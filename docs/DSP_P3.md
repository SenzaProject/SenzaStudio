# Senza Studio - Phase 3 (Advanced DSP)

Chain order: `scrub -> EQ -> bass -> compressor -> spatial -> imaging -> loudness normalizer -> master gain -> limiter -> meters`.
All modules are pure Kotlin in `:audio-dsp`, allocation-free and lock-free in `process`, bypass bit-exactly when disabled,
and are not yet attached to a live audio path (Phase 4). Parameter schema is **v3**.

## Parameter reference
| Module | Parameter | Range | Default |
|---|---|---|---|
| Bass | subBassDb (60 Hz low shelf) | -12..+12 dB | 0 |
| Bass | harmonics | 0..1 | 0 |
| Bass | punch | 0..1 | 0 |
| Bass | crossoverHz | 40..200 Hz | 90 |
| Imaging | midGainDb / sideGainDb | -12..+12 dB | 0 |
| Imaging | balance (attenuates opposite channel only) | -1..+1 | 0 |
| Imaging | monoBelowHz (0 = off) | 0 or 20..300 Hz | 0 |
| Spatial | mode (scene), intensity, stereoWidth | 6 scenes, 0..1, 0..2 | Natural, 0.5, 1 |
| Loudness | targetLufs / maxBoostDb / maxCutDb / responseSeconds | -30..-8 / 0..12 / 0..24 / 1..30 | -16 / 6 / 12 / 5 |

Everything is enabled per module (`enabled = false` by default) and passes through `sanitized()`.

## Algorithms
- **Bass.** 60 Hz low shelf; low band (Butterworth LP at crossover) is level-normalised by a peak envelope, passed through an
  asymmetric `tanh` (odd + even harmonics), restored, high-passed (4th order) and low-passed at 4x crossover, then added to both
  channels. Harmonic ratio is level-independent above about -34 dBFS. Punch is a fast/slow envelope transient shaper on the low band
  (extra gain at most 2 x punch). Protection: `tanh` bounds the generated signal; the always-on limiter bounds the output.
- **Imaging.** Mid/side gains, "mono below f" (4th-order high-pass on the side signal, content below f is exactly mono),
  balance. A mono input is only affected by mid gain and balance.
- **Spatial.** Side-only processing: `S' = width*S + ambience*reflections - crossfeed*delayed_lowpass(S)`. Mid is untouched, so
  the mono sum is exactly preserved. Scenes only change tuning (crossfeed depth, width lift, ambience level, room size), all
  scaled by intensity. Not implemented in P3: object/azimuth positioning and HRTF binauralisation (need head-related data and
  head tracking); this is not claimed anywhere in the UI.
- **Loudness.** ITU-R BS.1770 K-weighting (matches the ITU 48 kHz coefficients to 1e-9), momentary 400 ms, short-term 3 s,
  integrated with absolute (-70 LUFS) and relative (-10 LU) gates, sample peak and an approximate 4x true peak. LRA is not
  implemented. The normalizer is a slow gated AGC, not a limiter.

## Measured behaviour
Measured at 48 kHz. Reproduce with `./gradlew :audio-dsp:test`; CI uploads `audio-dsp/build/reports/p3-measurements.md`
(authoritative, generated by the Kotlin code). The values below were obtained with a numerically equivalent reference
implementation during development and are the thresholds the Kotlin tests assert.

**Bass harmonics** (50 Hz, 0.25 amplitude, dB relative to fundamental): harmonics 0.5 -> H2 -18.9, H3 -17.6; 1.0 -> H2 -16.1, H3 -6.6, H4 -14.2.
Fundamental change -0.6 dB (0.5) / -1.2 dB (1.0). H3 at 1.0 is -6.6 dBr at both 0.05 and 0.9 amplitude.
At harmonics = 1 the 90-120 Hz region is lifted by up to about +4.4 dB (harmonic content near the crossover).

**Sub shelf** (+12 dB setting): +11.8 dB @20 Hz, +10.9 @31.5 Hz, +6.0 @60 Hz, +0.9 @120 Hz, +0.05 @250 Hz, 0 @1 kHz.

**Punch** (60 Hz kick, 0.5 amplitude): attack peak +4.3 dB (0.5) / +7.7 dB (1.0); steady tone +0.3 dB; tail unchanged.

**Mono below 120 Hz** (side-only tone): -48 dB @30 Hz, -25 @60, -10 @100, -1.1 @200, 0 @500 Hz and above.

**Spatial** (intensity 1): mono-sum change 0.000 dB in every scene. Mono source gains side energy (side/in): Studio 0, Natural 0.03, Gaming 0.05,
Cinema 0.09, Immersive 0.12, Concert Hall 0.13. Stereo-noise level change: Natural 0.0, Studio 0.0, Concert Hall +0.5, Cinema +1.1, Gaming +1.5,
Immersive +2.2 dB. Crossfeed (Studio, i=1) on side signal: -4.8 dB @100 Hz, -2.9 @300, -0.1 @700, +1.2 @1.5 kHz, -0.5 @5 kHz.
Width 0.5/1/1.5/2 -> side -6.0/0/+3.5/+6.0 dB, mid unchanged.

**Loudness:** EBU reference (1 kHz, stereo, -23 dBFS) reads -22.99 LUFS; 100 Hz -20 dBFS stereo -21.83; 10 kHz -16.65; left-only -23.00.
Gating: 10 s at -20 then 10 s at -45 dBFS integrates to -20.06 (ungated mean would be -22.99). True peak estimate error <= 0.30 dB up to 20 kHz;
fs/4 sine at 45 degrees: sample peak -3.01 dBFS, true peak about 0 dBTP. Treat as an estimate, not a certified dBTP reading.

## Known P3 limitations
- Scene, delay-tap and coefficient changes are not cross-faded (clicks possible on abrupt changes).
- Scenes change level (up to +2.2 dB with Immersive); use the normalizer or master gain.
- Crossfeed adds up to +1.2 dB around 1.5 kHz on the side signal.
- Loudness meter / true peak run continuously on the output; profiled and optimised in P6 (`OPTIMIZATION_P6.md`).
- Clarity module (vocal clarity, HF detail) is not part of P3 and remains unavailable.
- Kotlin sources were written and the algorithms calibrated without a Kotlin compiler in the authoring environment; the
  CI run is the first compile and test run.
